## 2-1. 1차 작업 결과 (2026-11-24)

- `menu.js` 신설 — 6대 메뉴 + 하위 31개를 한 곳에서 선언. 네비·LNB·라우팅이 모두 이 트리에서 생성된다.
- 2단 라우팅 — `/about/greeting` 형태. `vercel.json` rewrite, `devserver.mjs` 의 SPA 경로 목록도 함께 갱신.
- 구 경로(`/business` `/rooms` `/programs` `/archive` `/news` `/apply`)는 새 경로로 자동 교체(replaceState) → 기존 링크 유지.
- 헤더: 대메뉴 hover 드롭다운 / 모바일은 햄버거 → 2단 아코디언.
- 서브페이지 공통 셸: 헤더(breadcrumb) + 좌측 하위메뉴(LNB) + 본문. 하위가 없는 섹션(04·05)은 전체폭.
- 기존 콘텐츠 배치: 인사말→`about/greeting`, 구 사업안내→`about/intro`, 비전·미션→`about/values`,
  연혁→`about/history`, 조직도→`about/people`, 치료실 소개→`about/facility`, 오시는 길→`about/directions`,
  구 프로그램 안내→`intensive`, 상담·문의→`guide/apply`, 자료실→`guide/archive`, 소식·공지→`guide/news`.
  (※ `about/intro` · `about/people` · `intensive` 는 임시 배치 — 3·4차에 구성안 원고/표로 교체)
- 나머지 20개 하위페이지는 "준비 중" 카드 + 상담신청 버튼.
- **부수 수정**: 모바일 미디어쿼리가 전부 죽어 있던 문제를 고침. React 가 인라인 스타일을
  `min-width: 1200px`(콜론 뒤 공백, `0`→`0px`)로 직렬화하는데 선택자는 공백 없는 authored 형태였음.
  더불어 ellipsis·grid 자식의 `min-width:auto` 로 인한 모바일 가로 스크롤도 제거.
- 스크립트 로드 경로를 `./x.js` → `/x.js` 로 변경(2단 경로에서 상대경로가 깨짐).
  같은 이유로 `image-slot.js` 의 사이드카 경로도 `/.image-slots.state.json` 로 고정.

## 2-2. 2차 작업 결과 (2026-11-24)

- **대문(#4)**: 히어로에서 아이들 사진 제거. 배경은 브랜드 그라데이션(네이비→틸)이고,
  관리자가 `hero-space` 슬롯에 **센터 공간·전경 사진**을 올린 경우에만 오른쪽 패널로 들어간다.
  문구도 구성안 표제(「마음이 자라고, 삶이 피어나는 곳」)로 교체, 「상담 신청」 버튼 추가.
  ※ 기존 `hero-main` 슬롯(아이들 사진)은 더 이상 쓰이지 않는다. DB 행·Blob 파일은 남아 있으므로
    정리를 원하면 따로 삭제 필요.
- **전문가 사진(#5)**: `director`(센터장 사진) 슬롯 삭제 → 인사말 왼쪽은 센터 문구 패널로 교체.
  `about/people` 은 사진 없는 **전문가 소개 카드**(자격·담당 영역·설명) + 팀 구성으로 재구성.
  실명·경력은 센터 원고 입고 후 `site-content.js` 의 `experts` 교체.
- **기관·협약·도서 사진(#5)**: `about/intro` 하단에 「센터의 기록」 추가 —
  기관 사진 `center-0~3`, 협약·위촉 `mou-0~3`, 발간 도서·자료 `book-0~3` (총 12개 슬롯, 캡션 포함).
  캡션 문구는 `site-content.js` 의 `galleryGroups`.
- **SNS(#7, 관리자 등록형)**: `sns_links` 테이블 + `/api/sns` + `/admin > SNS 관리` 탭 신설.
  - `kind=account` → 푸터 소셜 아이콘(기존 In/Yt/Bl 더미 교체, 등록 전에는 영역 자체가 숨김)
  - `kind=post` → 메인 「센터 소식, 더 가깝게」 카드 최대 4개 (등록 0건이면 섹션 숨김)
  - 주소는 http(s)만 허용(javascript: 등 차단). 썸네일 주소는 선택.
  - 자동 피드(유튜브 RSS·인스타 Graph API)는 추후 같은 테이블을 채우는 방식으로 확장 가능.
- **관리자 이미지 슬롯 목록** 동기화: `hero-main`·`director` 제거, `hero-space`·`center-*`·`mou-*`·`book-*` 추가.
- **부수 수정**: 로컬 devserver 가 API 핸들러의 비동기 오류로 죽던 문제(`await` 누락) 수정.

### 2차 이후 남은 확인
- SNS 실제 노출 확인은 센터 계정 주소를 `/admin > SNS 관리` 에 1건 등록한 뒤 가능(현재 테이블 비어 있음).
- 기관·협약·도서 이미지는 센터에서 파일을 받아 `/admin > 이미지 관리` 에서 업로드해야 채워진다.

## 3. 단계별 작업

### STEP 1. 정보구조(IA)·라우팅 재편  ← 다른 모든 작업의 전제

- `menu.js` 신설: 구성안 6대 메뉴 트리를 데이터로 선언 (`{ key, label, children:[{ key, label }] }`).
  - 01 센터소개 (7) / 02 심리평가 (9) / 03 상담 및 치료 (7) / 04 집중 프로그램 (표) / 05 외부기관 집단교육 (표) / 06 상담안내·센터소식 (6~7)
- 라우팅 2단 확장: `/about/greeting`, `/assessment/comprehensive` 형태.
  - `pageFromPath()` → `{ section, sub }` 파싱, 미지정 시 섹션 첫 하위로.
  - `vercel.json` rewrite를 섹션 prefix 와일드카드로 교체 (`/(about|assessment|therapy|intensive|outreach|guide)/(.*)` → `/index.html`), `/api/*`·`/admin` 은 제외.
- 헤더: 대메뉴 hover 드롭다운(데스크톱) / 아코디언(모바일 버거 메뉴 재활용).
- 서브페이지 공통 레이아웃: 좌측 하위메뉴(LNB) + breadcrumb + 본문. 지금은 페이지마다 레이아웃이 다르므로 공통 틀로 수렴.
- 구 경로 보존: `/business`, `/rooms`, `/programs` → 신 경로로 301 성격의 리다이렉트(SPA 내부 매핑) 처리.

### STEP 2. 콘텐츠 반영 (`홈페이지 내용.pdf` 기준)

- **01 센터소개** — 인사말(새 원고 전문 반영), 센터 소개, 핵심가치 3개(마음돌봄 / 나다운 성장 / 함께살이)로 기존 "따뜻함·전문성·연결" 교체, 연혁, 전문가 소개(텍스트), 시설 안내, 오시는 길.
- **02 심리평가** — 9개 하위페이지. 공통 템플릿: `리드문 → 주요 평가 및 검사 → 이런 경우에 도움이 됩니다 → 맺음문`. 원고가 그대로 있으므로 데이터 입력 작업.
- **03 상담 및 치료** — 7개 하위페이지. 공통 템플릿: `리드문 → 주요 상담 영역 → 세부 프로그램 표(대상/문제/목표) → 맺음문`.
- **04 집중 프로그램** — 구성안 표 14행을 그대로 렌더(특화영역 / 프로그램 구성). 단일 페이지 + 앵커.
- **05 외부기관 집단교육·집단상담** — 구성안 표 6행 그대로 렌더.
- **06 상담 안내 및 센터 소식** — 상담신청, 상담절차, FAQ, 공지사항, 자료실, 센터소식 (+ 내용 PDF에만 있는 "06-7 온라인 상담실" 포함 여부 확인 필요).
- 기존 `site-content.js` 의 `businesses` / `rooms` / `programs` 데이터는 신 구조(03·04·시설안내)로 흡수하고 중복 제거.

### STEP 3. 대문·이미지 정책 (#4, #5)

- `hero-main`: 아이들 활동 사진 → **센터 공간 사진 또는 브랜드 그래픽(그라데이션+패턴)** 기본. placeholder 문구도 "아이들이 활동하는 밝은 사진" → "센터 공간/전경 사진"으로 교체.
- `director`(센터장 사진) 슬롯 **제거**. 전문가 소개는 사진 없이 자격·전공·경력 텍스트 카드로.
- 갤러리 슬롯군 신설: `facility-0..5`(기관·치료실), `mou-0..5`(협약증서), `book-0..5`(발간 도서·자료).
  - 노출 위치: 센터소개 > 시설 안내 / 센터소개 하단 "기관 활동" 영역 / 홈 하단 신뢰 섹션.
  - 협약증서·도서는 캡션(기관명·연도·제목)이 필요하므로 이미지 슬롯 + 캡션 텍스트를 함께 관리하도록 DB(`gallery` 테이블) 또는 posts 재사용 중 하나 선택.
- `admin.html` 의 `SLOTS` 목록을 신설·삭제 슬롯에 맞춰 동기화.

### STEP 4. 센터 직접 운영 (#6)

- 매뉴얼 작성: `docs/관리자-매뉴얼.md` (+ 사이트 내 `/admin` "도움말" 탭에 동일 내용).
  - 로그인, 공지·행사·보도 글 작성/수정/삭제, 자료실 파일 업로드(용량 제한 ~3MB)·삭제, 이미지 교체(권장 해상도·비율), 팝업/띠배너 문구·기간·on/off, 비밀번호 변경, 실수했을 때 되돌리는 방법.
  - 화면 캡처 포함(실제 `/admin` 스크린샷).
- 관리자 기능 보강: 센터소식 게시판 추가, 갤러리(협약증서·도서) 등록, SNS 링크 관리, 자주 묻는 질문 항목 관리.
- 선택: 글쓰기 영역을 서식 가능한 에디터로 (현재 평문 텍스트 입력).

### STEP 5. SNS 연동 (#7)

- 푸터 소셜 아이콘(현재 `In / Yt / Bl` 더미, 링크 없음)에 실제 계정 URL 연결 + 아이콘 교체.
- 홈 하단 "센터 소식 한눈에" 섹션: 블로그 최신글 / 숏츠 / 인스타 카드.
- 구현 방식: **관리자 등록형 확정**. `sns_links` 테이블(또는 banners 재사용)에 `{ platform, url, title, thumb_url, sort, enabled }` 를 두고 `/admin > SNS` 탭에서 센터가 직접 등록·정렬·on/off.
  - 계정 URL 3개(블로그·인스타·유튜브)는 항상 푸터·상단 유틸바에 노출.
  - 홈 섹션 카드는 등록된 항목만 표시(0건이면 섹션 숨김) → 센터가 손 놓아도 빈 칸이 보이지 않음.
  - 추후 자동화(유튜브·네이버 RSS, 인스타 Graph API)는 같은 테이블을 채우는 방식으로 덧붙일 수 있게 설계.
- 공유 품질: 각 페이지 OG 태그(제목·설명·대표 이미지) 추가 — 인스타/카톡 공유 시 미리보기 정상 표시.

### STEP 6. 배포·도메인 전환 (#1)

- 기존 호스팅 종료 전 해야 할 일
  1. 기존 사이트 콘텐츠 백업(게시글·첨부파일·이미지) 및 이관 여부 결정.
  2. 도메인 소유 계정 확인 → Vercel 프로젝트에 도메인 추가 → DNS(A / CNAME) 변경. 전파 최대 24~48시간 감안해 **종료일 3~4일 전 전환**.
  3. 도메인 만료일과 호스팅 만료일이 다를 수 있으므로 각각 확인(도메인은 계속 갱신 필요).
  4. 메일(`info@…`)을 기존 호스팅에서 쓰고 있다면 메일 서비스 별도 이전 — 호스팅 종료 시 메일이 먼저 끊김.
- 전환 후: HTTPS 확인, 구 URL 리다이렉트, 네이버·구글 서치 등록(사이트맵 `sitemap.xml`, `robots.txt` 신규 추가 권장).

## 5. 참고 — 기술적 제약

- 프런트는 Design Canvas 런타임 기반 단일 HTML. 페이지가 50개 수준으로 늘면 `index.html` 이 지나치게 커지므로, 섹션별 콘텐츠를 `content/*.js` 로 분리하고 템플릿은 공통 1~2종으로 수렴해야 유지보수가 가능합니다.
- `<svg>` 내부 `{{ }}` 바인딩 미지원 → 아이콘은 data URI `<img>` 방식 유지 (기존 커밋 `6e6d59b` 이유).
- 자료실 업로드는 base64 경유로 ~3MB 제한. 협약증서·도서 스캔은 업로드 전 리사이즈 필요.
