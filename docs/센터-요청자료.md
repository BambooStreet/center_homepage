> 참고: 보내주신 「홈페이지 내용」 문서에서 **청년 상담(03-7)의 부제가 부모·가족상담(03-6)과
> 동일하게 「가족의 마음을 이해하고 관계를 회복하는 시간」** 으로 적혀 있습니다. 청년 상담에 맞는
> 부제를 함께 주세요.

### 평가 페이지 양식 (이미 올라간 7개 페이지와 동일한 틀)

```
제목      : 기질평가
한 줄 소개 : 나의 고유한 기질적 특성을 이해합니다
설명      : 2~3문장
주요 평가 및 검사 : 검사명 — 간단한 설명   (여러 개)
이런 경우에 도움이 됩니다 : 4~6줄
맺음문    : 1문장
```

### 상담 페이지 양식

```
제목      : 청년 상담
한 줄 소개 : (청년 상담에 맞는 부제)
설명      : 2~3문장
주요 상담 영역 : 영역명 — 설명   (4개 내외)
세부 프로그램  : 프로그램명 / 주요 대상 및 문제 / 주요 목표   (표, 3~5개)
강조 문구 + 맺음문 : 각 1문장
```

### 그 밖에 비어 있는 한 줄

- **청소년 상담 > 주요 상담 영역의 ‘진로’ 항목** — 원문에 「진로 :」 까지만 있고 설명이 비어 있어
  현재는 제외해 두었습니다. 한 줄만 주시면 넣겠습니다.

| 들어갈 곳 | 장수 | 비고 |
| --- | --- | --- |

| 센터 소개 > 협약 · 위촉 | 4 | 업무협약서·위촉장·감사패 **스캔본** + 각 **기관명·연도** |
| 센터 소개 > 발간 도서 · 자료 | 4 | 표지 이미지 + **도서명·출판사·발행연도** |

## 5. 운영 관련 확인 사항

1. **웹호스팅 종료일** — 「15일이면 종료」로 전달받았습니다. **정확한 날짜(연·월·일)** 와
   - 도메인을 어느 업체/계정에서 관리하는지
   - 지금 쓰시는 **이메일(@센터도메인)이 그 호스팅에 붙어 있는지** (붙어 있다면 메일이 먼저 끊깁니다)
   를 알려주세요. 주소 이전은 전파에 1~2일 걸려 종료 3~4일 전에는 작업해야 합니다.
2. **기존 홈페이지 자료** — 지금 사이트의 게시글·첨부파일 중 옮겨야 할 것이 있는지.
3. **온라인 상담실** — 「홈페이지 내용」에만 있고 구성안에는 없는 항목입니다.
   운영하실 건지, 운영한다면 (a) 신청 폼인지 (b) 비공개 1:1 게시판인지.
4. **상담 신청 방식** — 전화만 받으실지, 홈페이지 신청 폼도 두실지.
5. **공지사항·자료실 초기 등록분** — 오픈 시점에 올려둘 공지와 부모교육 자료.
